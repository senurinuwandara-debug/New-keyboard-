# Mathra Keyboard

Sinhala + English keyboard by **Denuwan Akash** (TikTok: @mathra_quotes_1, GitHub: denuvan-akash).

Built on the open-source FlorisBoard project (Apache License 2.0, see LICENSE).

## Build
Open in Android Studio (Hedgehog or newer, JDK 17+, NDK as in `gradle/tools.versions.toml`) and run `./gradlew assembleDebug`.

## What changed from upstream
- Renamed to Mathra Keyboard, new applicationId `com.mathra.keyboard`, new logo/launcher icon
- New dashboard (Home) and About screens
- 6 new Mathra themes (Gold, Neon Night, Pink, Honey Day, Ocean Glow, Midnight Black)
- New "Sinhala (Mathra)" layout + `si-lk` language preset
